# Career Companion Platform

A full-stack web application designed to help students prepare for their careers by providing interview preparation, skill tracking, learning resources, job application management, and productivity analytics.

## Features

- User Registration and Login
- Career Dashboard
- AI Interview Preparation
- Skill Roadmap and Skill Tracking
- Job Finder and Application Tracker
- Learning Hub and Course Progress
- Productivity Analytics
- MySQL Database Integration

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Development Tools
- Visual Studio Code
- Git & GitHub
